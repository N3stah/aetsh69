# Arcade Games
The AETSH-69 Arcade features browser-based games built as robust, typed React components. Available games include:
1. Snake: Classic snake game with speed increase per level, wall colors, game over screen, mobile touch controls.
2. Tetris: Full implementation with 7 tetrominoes, rotation, line clearing, scoring (100/300/500/800), level speed increase, next piece preview, hold piece.
3. 2048: 4x4 grid with swipe/arrow controls, tile merging, score tracking, win/lose detection.
4. Memory Match: Card matching game with 6x4 grid, flip animations, move counter, timer, difficulty levels.
5. Pong: Two-player or vs CPU with ball physics, paddle control, score to 10, CPU difficulty levels.

Global leaderboard backend is wired. Scores are stored in the database per game. Users can view top 10 scores per game.
