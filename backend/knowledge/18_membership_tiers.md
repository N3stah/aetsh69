# Membership Tiers
The AETSH-69 ecosystem offers three membership tiers:

1. Explorer (Free): Public content access, general AETSH-69 AI chat (limited requests).
2. Builder (KSh 1,500/month): Priority AI access, exclusive tutorials, Q&A calls, download access. Payment via M-Pesa STK Push.
3. Enterprise (Custom): Everything in Builder plus dedicated Slack, custom builds, SLA. Contact for pricing.

Members can upgrade via the /upgrade page using M-Pesa Daraja STK Push. Payment status is tracked in the database.
